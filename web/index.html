🔧 Installation Flutter

Pour lancer l'application, installez Flutter :

# 1. Télécharger Flutter SDK # https://flutter.dev/docs/get-started/install/windows # 2. Ajouter au PATH C:\flutter\bin # 3. Installer les dépendances flutter pub get # 4. Lancer l'application flutter run

💡 Note

Le code source AtlasMove est déjà créé dans ce dossier. Une fois Flutter installé, vous pourrez lancer l'application complète avec splash screen, login, signup et upload d'images.
